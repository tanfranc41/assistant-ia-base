# Architektur des Projekts

- **frontend/index.html**: nur Demo-Oberfläche, simuliert An- und Abmeldung; keine echte Authentifizierung.
- **backend/**: Ordner bewusst leer gelassen, für zukünftige Entwicklungen reserviert.

## Was simuliert wird
- Demo-Benutzer.
- An-/Abmeldestatus wird nur im Frontend gespeichert.

## Was noch nicht umgesetzt ist
- Echte Anmeldung oder Kontoverwaltung.
- Sicherheit (Sitzungen, Tokens, Speicherung).
- API oder Serverlogik.

## Zu beachtende Regeln
- Vorerst keine Backend-Logik hinzufügen.
- Keine echte Authentifizierung integrieren.
- Jede Änderung muss über eine Pull Request erfolgen.
