# Statut du projet
- La phase de démonstration est officiellement close.
- Le projet est volontairement figé dans son état actuel.

## Règles finales (verrouillées)
- Démo frontend uniquement.
- Aucune logique backend.
- Pas d'authentification réelle.
- Pas de persistance.
- Pas d'auto-détection de langue.
- i18n limitée aux traductions statiques dans les fichiers.
- Le français est la langue de référence.
- Approche documentation-first.
- Toute modification doit passer par une Pull Request.

## Checklist avant toute Pull Request
- Le changement est documenté.
- Le périmètre reste démo uniquement.
- Aucune logique backend ou d'authentification n'est ajoutée.
- Les règles i18n sont respectées.
- La version française est mise à jour en premier.
- Les autres langues sont alignées si applicable.

## Évolution future
- Toute nouvelle fonctionnalité ou implémentation réelle impose l'ouverture d'une nouvelle phase projet.
- Ce document entérine la fin du périmètre de démonstration.
