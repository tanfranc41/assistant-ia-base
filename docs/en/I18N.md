# I18N (internationalization)

## Supported languages
- French (reference)
- English
- Dutch
- German

## Translation structure in `frontend/index.html`
- `translations` object with one entry per language (`en`, `fr`, `nl`, `de`).
- Each entry includes: `langName`, `title`, `labels` (`language`, `username`, `status`), `actions.logout`, `notice`, `statuses` (`loggedOut`, `authenticated`), `users` (`guest`, `demo`).
- The HTML reads these keys to update the title, labels, button, and messages.

## How the language selector works
- `<select id="language-select">` lists languages and displays their `langName`.
- On change, `currentLang` is updated and `render()` reloads translations and updates the DOM.
- No storage: the selection is volatile and disappears on reload.

## What is simulated (demo only)
- Text updates happen only in the frontend.
- User state and auth token are kept in memory inside the page.

## What is not implemented yet
- Backend or API to load languages.
- Real authentication or token validation.
- Persistence of the language choice.
- Automatic language detection (browser, user profile).

## Rules for future evolution
- Keep French as the reference and align keys with the existing structure.
- Add any new language or key to every entry in `translations`.
- Do not add backend logic or persistence while the project stays in demo mode.
- Document any new key or rule in this file and its localized equivalents.

## Demo constraints for translations
- Keep language codes exactly `en`, `fr`, `nl`, `de` and lowercase so they match the `<option value>` list and `document.documentElement.lang`.
- Translations must stay plain text (no HTML tags, no interpolation). Colons for labels are added by the UI, so do not include them in the strings.
- Keep labels/messages short enough to fit the 360px card without overflow; favor concise wording.
- The demo bundle must stay self-contained: translations remain inline in `frontend/index.html`, with no network loading, persistence, or auto-detection while in demo mode.
