# Project Architecture

- **frontend/index.html**: demo interface only, simulates logged in/logged out state; no real authentication.
- **backend/**: folder left empty by choice, reserved for future development.

## What is simulated
- Demo user.
- Logged-in/logged-out state stored on the frontend only.

## What is not implemented yet
- Real login or account management.
- Security (sessions, tokens, storage).
- API or server logic.

## Rules to follow
- Do not add backend logic for now.
- Do not integrate real authentication.
- Every change must go through a Pull Request.
