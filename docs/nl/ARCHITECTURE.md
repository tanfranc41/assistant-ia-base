# Architectuur van het project

- **frontend/index.html**: alleen demo-interface, simuleert ingelogd/uitgelogd zijn; geen echte authenticatie.
- **backend/**: map bewust leeggelaten, gereserveerd voor toekomstige ontwikkelingen.

## Wat wordt gesimuleerd
- Demogebruiker.
- In-/uitgelogde status wordt alleen aan de frontend-kant opgeslagen.

## Wat is nog niet geïmplementeerd
- Echte login of accountbeheer.
- Beveiliging (sessies, tokens, opslag).
- API of serverlogica.

## Te respecteren regels
- Voeg voorlopig geen backendlogica toe.
- Integreer geen echte authenticatie.
- Elke wijziging moet via een Pull Request gebeuren.
