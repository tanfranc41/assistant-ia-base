# Registre de décisions – phase de préparation du produit réel

## Décisions actées
- Clôture de la phase de démonstration.
- Adoption d’une approche documentation-first.
- Séparation stricte frontend / backend.
- Règles multilingues avec le français comme langue de référence.
- Changements via Pull Requests uniquement.

## Décisions repoussées
- Choix du framework backend.
- Choix de la base de données.
- Méthode d’authentification.
- Mise en place du prestataire de paiement.
- Sélection du fournisseur IA.

## Points ouverts
- Stratégie d’hébergement.
- Pipeline de déploiement.
- Monitoring et logging.
- Principes du modèle de données.

## Critères de passage à l’implémentation
- Périmètre fonctionnel approuvé.
- Exigences de sécurité définies.
- Règles de gestion des données validées.
- Budget et calendrier confirmés.
