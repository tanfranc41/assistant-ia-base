# DEMO

## Ce que la démo montre
- Interface frontend unique avec sélecteur de langue et carte utilisateur.
- Passage invité/démo et affichage de l’état connecté/déconnecté.
- Messages statiques pour illustrer notifications et titres.

## Ce qui est simulé
- Changement de langue entièrement côté frontend, sans réseau ni persistance.
- Stockage en mémoire du nom d’utilisateur et d’un jeton fictif.
- Déconnexion qui efface simplement l’état local.

## Hors périmètre
- Authentification réelle, gestion de comptes ou validation de jeton.
- Backend, API, base de données ou stockage persistant.
- Sécurité, observabilité et performance de niveau production.

## Ce n’est pas un produit
- Démo gelée : aucune évolution frontend/backend tant que le périmètre n’est pas validé.
- Ne pas utiliser en production ni pour des données réelles.
- Le comportement peut changer ou être supprimé sans garantie de rétrocompatibilité.
