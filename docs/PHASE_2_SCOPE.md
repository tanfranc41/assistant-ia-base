# Phase 2 – Scope Definition

## Statut
- La Phase 2 n’est **pas démarrée**.
- **Aucune implémentation n’est autorisée** à ce stade (document de cadrage uniquement).

## Ce que la Phase 2 peut couvrir (niveau conceptuel uniquement)
- Logique backend réelle.
- Authentification réelle.
- Persistance des données.
- Conception d’API.
- Considérations de sécurité.

## Ce que la Phase 2 ne doit pas contenir pour l’instant
- Aucun code de production.
- Aucune base de données ni aucun identifiant/secret.
- Aucun déploiement ni configuration d’hébergement.

## Porte de décision
- Le lancement de la Phase 2 nécessite une validation explicite préalable (go/no-go).

## Lien avec la Phase 1
- La Phase 1 reste gelée et inchangée ; aucune modification n’est autorisée sur la démo statique actuelle.

- Cette version est la référence en français.
- Les traductions seront alignées ultérieurement sur cette version de référence.
