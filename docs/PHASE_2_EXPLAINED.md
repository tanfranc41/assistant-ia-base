# Phase 2 – Explication simple

## À quoi sert la Phase 2
Cette phase sert à prendre le temps de réfléchir avant de coder, pour éviter les erreurs.

## Ce qui est déjà fait
La démo est terminée, figée, et les documents sont déjà là.

## Ce qu’on a le droit de faire maintenant
- Réfléchir
- Discuter
- Écrire des idées
- Poser des règles

## Ce qu’on n’a PAS le droit de faire
- Aucun code du côté serveur
- Aucune base de données
- Aucune authentification réelle
- Aucun déploiement

## Quand le vrai travail commencera
Le vrai travail commencera seulement après une décision claire pour avancer.
